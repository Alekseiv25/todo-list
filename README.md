# todo list

A to-do list in TypeScript: add, edit (double-click), complete, delete, search and filter tasks,
with counters and a light/dark theme. Works on phones and desktops; tasks are kept in your browser.

```sh
npm install
npm start        # dev server at http://localhost:1234
npm test         # unit tests
npm run build    # rebuild dist/ for static hosting
```

The site is published to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
